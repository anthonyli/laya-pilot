# Excel 用例模板

没有现成模板时，复制 [assets/test-cases-template.xlsx](../assets/test-cases-template.xlsx) 到自己的工作目录，另存为本次任务的用例文件。模板只有一个“测试用例”工作表，首行为表头，从第二行开始每行填写一条用例，可继续向下新增行。

| 列       | 如何填写                                                       |
| -------- | -------------------------------------------------------------- |
| 用例编号 | 建议填写不重复的编号，例如 `001`；模板按文本保存，保留前导零   |
| 用例名称 | 建议填写简明目的，例如“按名称查询客户”                         |
| 前置条件 | 可选，写明需要的登录角色、页面状态及已准备的数据               |
| 测试数据 | 可选，写本例使用的明确值；步骤中也写清具体输入，不依赖隐含替换 |
| 测试步骤 | 必填，写清控件名称、动作和输入；多个步骤在同一单元格内换行编号 |
| 预期结果 | 必填，写可观察、可核验的结果，避免只写“操作成功”               |

模板已预填三条用例，编号以 `DEMO-` 开头、名称标注“【示例】”：

| 编号     | 场景           | 展示的写法                                           |
| -------- | -------------- | ---------------------------------------------------- |
| DEMO-001 | 搜索按钮可见   | 单个观察步骤与明确的按钮可见断言                     |
| DEMO-002 | 按名称搜索客户 | 前置条件、测试数据、清空/输入/点击等多步骤与列表断言 |
| DEMO-003 | 重置搜索条件   | 独立准备筛选状态、执行重置、验证其他客户恢复显示     |

这些示例对应 [源码 demo](https://github.com/anthonyli/laya-pilot#体验-demo) 的 `/customers` 页面，使用默认的“Laya演示客户”“常规客户乙”“常规客户丙”数据。交付包不包含 demo 服务；示例用于学习写法，不代表你的业务系统具备相同控件和数据。**运行自己的系统前，修改或删除示例行；执行器不会自动跳过 `DEMO-` 用例。**

请用真实业务内容填写。浅黄色的步骤和预期结果列是必填区；空行不计作用例。前置条件需在执行前确认，不能只因填入表格就认为已满足。密码、API 密钥和登录态放在本机配置中，不写进 Excel。目标地址在每次任务中提供。

填写后先检查解析结果：

```bash
node scripts/run.mjs --excel '/absolute/path/my-cases.xlsx' --inspect
```

原始模板会读取出三条示例用例；检查时确认已替换为本次业务用例，并核对用例数量、步骤、预期结果与导入警告，再执行测试。输入文件不会被测试结果覆盖。

已有其他 Excel 用例可直接使用，执行器支持多种表头，不必套用此模板。希望 AI 从页面生成新用例时，只需提供目标地址和测试范围；生成器使用自身的内置格式，不需要这份示例模板。这里的六列模板不用于 `--template-excel`，该参数仅用于明确指定生成格式的场景。
